# Source Directory

This is the main source directory for the KGP Client Template project.

## Structure

This directory will contain all the React TypeScript source code for the enhanced headless WordPress e-commerce system.

### Planned Structure

- `api/` - API integration layer (WordPress, WooCommerce, Social Media, Payments)
- `components/` - React components organized by feature
- `hooks/` - Custom React hooks for state management and data fetching
- `store/` - State management (Zustand stores)
- `types/` - TypeScript type definitions
- `utils/` - Utility functions and helpers
- `config/` - Application configuration files
